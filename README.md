# 0826Machine-Learning

## 📌 專案介紹

本專案為 Python 與 Machine Learning 的課程實作成果，
主要使用 Jupyter Notebook 進行資料分析、資料前處理、
特徵工程、資料降維、迴歸模型與正則化等機器學習練習。

本專案從 Dataset 開始，依序進行 Data Preprocessing、
Feature Engineering、Dimensionality Reduction、
Model Training 與 Prediction，建立完整的 Machine Learning Workflow。

透過實際操作，將課程中學習的 Python、Pandas、
Scikit-learn 等工具應用於資料分析與機器學習模型建立。

---

## 🎯 學習目標

本專案主要練習以下 Machine Learning 技術：

- Python 資料處理

- Data Preprocessing

- Dimensionality Reduction

## 📊 專案內容

### 1. 📂 資料前處理

針對原始 Dataset 進行資料分析與前處理。

主要內容：

- Dataset 資料結構分析
- Data Cleaning
- 缺失資料處理
- 資料型態確認
- 資料轉換
- Data Preprocessing

將原始資料整理成適合 Machine Learning
模型使用的格式。

---

### 2. 🔧 Feature Engineering

針對 Dataset 中的特徵進行整理與轉換。

主要練習：

- Feature Selection
- Feature Transformation
- 特徵整理
- 特徵標準化
- 建立模型所需的輸入資料

透過 Feature Engineering，
讓資料更適合後續模型訓練。

---

### 3. 📉 Dimensionality Reduction

進行資料降維（Dimensionality Reduction）練習。

主要目的：

- 降低資料維度
- 減少特徵數量
- 簡化資料結構
- 協助資料分析
- 降低模型處理複雜度

透過資料降維了解高維度資料的處理方式。

---

### 4. 📈 Linear Regression

使用 Linear Regression 建立迴歸模型，
學習輸入特徵與預測結果之間的關係。

基本流程：

Dataset → Data Preprocessing → Feature Engineering
→ Linear Regression → Model Training → Prediction

並將迴歸模型應用於房價預測相關練習。

---

### 5. 🧮 Regularization

進一步學習 Linear Models 與 Regularization。

Regularization 用於控制模型複雜度，
並降低模型發生 Overfitting 的風險。

主要練習：

- Linear Models
- Regularization
- Model Training
- Model Comparison

---

### 6. 🔄 Machine Learning Pipeline

使用 Machine Learning Pipeline
將資料處理與模型訓練流程整合。

主要流程：

Dataset
↓
Data Preprocessing
↓
Feature Transformation
↓
Machine Learning Model
↓
Model Training
↓
Prediction
