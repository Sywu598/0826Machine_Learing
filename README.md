# 0826Machine-Learning

## 📌 專案介紹

本專案為 Python 與 Machine Learning 的課程實作成果，
主要使用 Jupyter Notebook 進行資料分析、資料前處理、
特徵工程、資料降維、迴歸模型與正則化等機器學習練習。

本專案從 Dataset 開始，依序進行 Data Preprocessing、
Feature Engineering、Dimensionality Reduction、
Model Training 與 Prediction，建立完整的 Machine Learning Workflow。

透過實際操作，將課程中學習的 Python、Pandas、
Scikit-learn 等工具應用於資料分析與機器學習模型建立。

---

## 🎯 學習目標

本專案主要練習以下 Machine Learning 技術：

- Python 資料處理

## 📓 Notebook 實作內容

### 1. 資料前處理

**Notebook：**

`1 資料前處理-Pre Model Workflow and Data Preprocessing.ipynb`

主要內容：

- Dataset 資料結構分析
- Data Cleaning
- 缺失資料處理
- 資料型態確認
- 資料轉換
- Data Preprocessing
- Feature Engineering

將原始 Dataset 整理成適合 Machine Learning
模型使用的格式。

---

### 2. 資料降維

**Notebook：**

`2 資料降維-Dimensionality Reduction Techniques.ipynb`

主要內容：

- Dimensionality Reduction
- Principal Component Analysis（PCA）
- Feature Transformation
- 減少特徵數量
- 簡化高維度資料

透過資料降維方法了解高維度資料的處理方式，
並降低資料的複雜度。

---

### 3. 迴歸模型與正則化

**Notebook：**

`3 迴歸模型-Linear Models and Regularization.ipynb`

主要內容：

- Linear Regression
- Linear Models
- Model Training
- Model Evaluation
- Regularization
- Model Comparison
- Prediction

並將 Linear Regression 應用於房價預測相關練習。
