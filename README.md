# Machine Learning - House Price Prediction

## Project Description

使用 Python 與 Jupyter Notebook 進行資料整理、資料前處理與機器學習實作。

本專案以房價資料集為例，練習從資料前處理、特徵處理到建立迴歸模型的完整流程。

## Skills

- Python
- Jupyter Notebook
- Data Preprocessing
- Data Cleaning
- Feature Engineering
- Dimensionality Reduction
- Linear Regression
- Regularization
- Machine Learning
